## Descripción

El **Visor Registral Optimizado** es un sistema web desarrollado para el **Registro Público de la Propiedad**, diseñado para facilitar la búsqueda de inscripciones y sus apéndices mediante diversos criterios, como:
- Oficina registral
- Tipo de documento
- Número de libros
- Años de registro

El sistema permite localizar documentos de manera precisa y visualizarlos en formatos **PDF, JPG o PNG**.

📌 **Estado del Proyecto:** En fase de codificación del **frontend**, sin consumo de APIs.

## Funcionalidades Principales

### 🔍 Búsqueda de Documentos

![vistaBuscar](https://github.com/user-attachments/assets/c0e7f983-ff85-4eb3-a077-981d6b218b07)

El usuario ingresa los datos requeridos para realizar la búsqueda de documentos en el sistema.

### 📋 Resultados de la Búsqueda
![vistaResultados](https://github.com/user-attachments/assets/ee99ba9a-79e1-4c9f-9f04-17a1073243f5)

Los resultados se muestran en una tabla con enlaces para visualizar los documentos en su formato correspondiente.

### 📌 Menú de Navegación
![menuOpciones](https://github.com/user-attachments/assets/0ae8cc95-2c4f-4cab-b19f-597aa4a7b542)

El sistema cuenta con un menú lateral que se despliega al hacer clic en el icono, permitiendo navegar entre secciones de manera intuitiva.

### ❌ Página de Error 404

Incluye una página de error 404 para manejar redirecciones incorrectas y mejorar la experiencia del usuario.

## Tecnologías Utilizadas

Este sistema fue desarrollado con **Angular 15**, implementando:
- **Rutas y Navegación** para manejar las diferentes secciones.
- **Interfaces y Componentes Reutilizables** para estructurar el frontend.
- **Validación de Formularios** para asegurar que los datos ingresados sean correctos.
- **Diseño Responsivo** para adaptarse a distintos dispositivos.

## Instalación y Uso

Si deseas ejecutar este proyecto localmente, sigue estos pasos:

```bash
# Clona el repositorio
git clone https://github.com/MoniLopez/ViRO15.git

# Entra en la carpeta del proyecto
cd viro15

# Instala las dependencias
npm install

# Ejecuta el proyecto
gng serve --open
```

Asegúrate de contar con **Node.js** y **Angular CLI** instalados en tu equipo.
